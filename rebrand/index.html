How the work gets done

Most things get built by adding.

Another tool. Another dashboard. Another subscription. Something breaks, so a new part gets bolted on, and the part that broke stays where it is.

The question here is never what else could go in. It is what shouldn't be there at all. If removing something would go unnoticed, it should be removed. It usually stays anyway, because taking things out is harder than putting them in.

A city runs three systems that cannot talk to each other. A church uses software built to close sales. A founder rents his own identity from a platform he does not control. Different rooms, same problem: things that should be one thing are five, and nobody remembers why.
